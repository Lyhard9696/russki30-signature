# RUSSKI 30 SIGNATURE COMPLET

Ce dossier déploie **un seul site web HTTPS** avec l'interface française et le professeur IA optionnel, via Render.

**Commence par : `GUIDE-INSTALLATION.md`**. Ne publie pas la clé API dans GitHub.

Fichiers principaux : `index.html` (site), `styles.css` (thème Signature), `app.js` et autres `.js` (cours/exercices), `server.py` (serveur same-origin protégé par Basic Auth + quotas simples), `render.yaml` (déploiement), `manifest.webmanifest` et `sw.js` (installation PWA).

Le mode hors ligne reste soumis aux limites du navigateur, et le professeur IA nécessite toujours Internet. Les progrès sont enregistrés localement, sans synchronisation cloud.
